- Hysteria2 backends: the stats socket takes a user's name after the address ("<address> <name>") and then also gives that user's sessions from the address one by one (own: RTT, packets, Brutal's rate and acknowledged share), beside the aggregates; for raycontrol's channel probes, so that a client behind carrier-grade NAT sees its own session and nobody else's
