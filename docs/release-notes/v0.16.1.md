Security: built with Go 1.26.10 instead of 1.26.0, which carried known vulnerabilities in the standard library reachable from niko-server's HTTP/2 and TLS servers (among them GO-2026-6617, an HTTP/2 server crash; GO-2026-6603, HTTP/2 memory exhaustion; GO-2026-4870, a TLS 1.3 KeyUpdate denial of service). Nothing else changes in behaviour; IPC, configs and the users file are as in v0.16.0.

- go.mod names `toolchain go1.26.10`, so CI and the release build use it.
- Modules: golang.org/x/net v0.62.0, github.com/andybalholm/brotli v1.2.8, github.com/klauspost/compress v1.20.4 (their advisories were not reachable on the server, now clean).
- CI runs govulncheck on every push and pull request.

Безопасность: сборка на Go 1.26.10 вместо 1.26.0, в стандартной библиотеке которого были известные уязвимости, достижимые из HTTP/2- и TLS-серверов niko-server (среди них GO-2026-6617 — падение HTTP/2-сервера; GO-2026-6603 — исчерпание памяти HTTP/2; GO-2026-4870 — отказ в обслуживании через KeyUpdate TLS 1.3). Поведение не меняется; IPC, конфиги и файл пользователей — как в v0.16.0.

- В go.mod — `toolchain go1.26.10`: на нём собирают CI и релиз.
- Модули: golang.org/x/net v0.62.0, github.com/andybalholm/brotli v1.2.8, github.com/klauspost/compress v1.20.4 (их уязвимости на сервере были недостижимы, теперь их нет).
- CI запускает govulncheck на каждом push и pull request.
