- Hysteria2 backends: options.probe sends streams and datagrams for a name to a loopback address of the node (raycontrol's channel probes through the tunnel, probe-v1); replies come from the name; every other destination stays public-only
- Config check: the probe address must be loopback, the name a DNS name, and only the Hysteria2 backends take it
- dnstt backend: the channel of responses is closed by its only sender, so stopping the backend can no longer race a send (a possible "send on closed channel" panic)

- Бэкенды Hysteria2: options.probe направляет потоки и датаграммы для имени на адрес loopback ноды (замер канала raycontrol через туннель, probe-v1); ответы приходят от имени; все остальные назначения по-прежнему только публичные
- Проверка конфига: адрес probe — только loopback, имя — имя DNS, принимают его только бэкенды Hysteria2
- Бэкенд dnstt: канал ответов закрывает его единственный отправитель, поэтому остановка бэкенда больше не гоняется с отправкой (возможная паника «send on closed channel»)
