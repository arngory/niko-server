Security: built with Go 1.26.11 instead of 1.26.10. Go 1.26.10 carries GO-2026-6859, a crash of an HTTP/1 server in net/http; niko-server has one HTTP/1 server, the Yggdrasil listener's empty 404 for a visitor who is not a Yggdrasil peer. Nothing else changes in behaviour; IPC, configs and the users file are as in v0.17.0.

- go.mod names `toolchain go1.26.11`, so CI and the release build use it.
- CI: GitHub Actions are pinned by commit, not by a moving tag.

Безопасность: сборка на Go 1.26.11 вместо 1.26.10. В Go 1.26.10 есть GO-2026-6859 — падение HTTP/1-сервера в net/http; у niko-server такой сервер один: пустой 404 слушателя Yggdrasil посетителю, который не является узлом Yggdrasil. Поведение не меняется; IPC, конфиги и файл пользователей — как в v0.17.0.

- В go.mod — `toolchain go1.26.11`: на нём собирают CI и релиз.
- CI: действия GitHub Actions закреплены по коммиту, а не по подвижному тегу.
