Draft. The DNS front checks the device's tag of slipstream queries itself; the masterdns service key changes while it runs.

- DNS front: dns.zones[].tag "slipstream" with auth_keys_file (raycontrol docs/spec/slipstream-v1.md §2). The front decodes each query's data (base32 before the zone), finds the device's key by the dnsauth-v2 hint, checks the tag over the QUIC packet, and passes the query to the backend rebuilt (header, the question as it came, an OPT without options) only when it holds. Anything else gets NOERROR without records and never reaches the server (stats: untagged). The backend is the fork's slipstream server (arngory/slipstream, --front-socket) in mode packet.
- masterdns: the service key changes while the server runs (raycontrol docs/spec/masterdns-key-rotation.md): encryption_key_file holds one key a line, the current first, then the previous one while it is still taken; the file is reread every 5 s by content. A session stays on the key of its SESSION_INIT; the sessions of a key gone are closed at once. From the client's fork at 56ed4b2 (embed.NewServer, SetKeys), which also tags with dnsauth-v2.

Черновик. DNS-фронт сам проверяет метку устройства в запросах slipstream; ключ сервиса masterdns меняется на ходу.

- DNS-фронт: dns.zones[].tag "slipstream" с auth_keys_file (raycontrol docs/spec/slipstream-v1.md §2). Фронт разбирает данные запроса (base32 перед зоной), находит ключ устройства по подсказке dnsauth-v2, проверяет метку над пакетом QUIC и только тогда передаёт запрос бэкенду пересобранным (заголовок, вопрос как пришёл, OPT без опций). Остальное получает NOERROR без записей и до сервера не доходит (счётчик untagged). Бэкенд — сервер slipstream из форка (arngory/slipstream, --front-socket) в режиме packet.
- masterdns: ключ сервиса меняется, пока сервер работает (raycontrol docs/spec/masterdns-key-rotation.md): в encryption_key_file по ключу на строку, первым текущий, следом прежний, пока он принимается; файл перечитывается раз в 5 с по содержимому. Сессия остаётся на ключе своего SESSION_INIT; сессии снятого ключа закрываются сразу. Из форка клиента 56ed4b2 (embed.NewServer, SetKeys), который также подписывает по dnsauth-v2.
