- udpmux: the front serves UDP 443; a flow (client and local address) is pinned by its first datagram that classifies and forgotten after the idle time
- QUIC Initial packets (v1 and v2) are decrypted with their public keys to read the ClientHello's server name, also when it spans several packets
- Salamander flows are recognised by opening the first packet with the password; the backend gets the datagrams still obfuscated
- Fakes, names not routed and garbage are dropped without pinning the flow
- Backends hy2-masq and hy2-obfs on sing-quic: users from users_file, reloaded on SIGHUP and when the file changes, without dropping sessions; TLS 1.3 with X25519MLKEM768 only; an empty 404 for anyone without a password; streams and datagrams go out to public addresses only
- up_mbps is the per-connection ceiling of the server's Brutal: it sends at min(up_mbps, the client's rate) when the client gives one, BBR otherwise

- udpmux: фронт обслуживает UDP 443; поток (адрес клиента и локальный адрес) закрепляется первой датаграммой, прошедшей классификацию, и забывается после бездействия
- Пакеты QUIC Initial (v1 и v2) расшифровываются открытыми ключами, чтобы прочитать имя из ClientHello, в том числе когда он занимает несколько пакетов
- Потоки salamander распознаются по первому пакету, который открывается паролем; бэкенд получает датаграммы ещё обфусцированными
- Фейки, имена без маршрута и мусор отбрасываются, не закрепляя поток
- Бэкенды hy2-masq и hy2-obfs на sing-quic: пользователи из users_file, перечитываются по SIGHUP и при изменении файла без разрыва сессий; TLS 1.3 только с X25519MLKEM768; пустой 404 для всех без пароля; потоки и датаграммы выходят только на публичные адреса
- up_mbps — потолок серверного Brutal на одно соединение: сервер шлёт со скоростью min(up_mbps, темп клиента), если клиент его сообщил, иначе BBR
